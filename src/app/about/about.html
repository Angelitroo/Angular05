Aplicación desarrollada como proyecto práctico utilizando Angular y Firebase, centrada en la gestión de eventos nocturnos con control de roles y autenticación.

Herramientas y tecnologías utilizadas

  • Angular: 20 (componentes standalone)
  • TypeScript: 5.x
  • HTML5 / CSS3
  • Bootstrap: 5.3
  • Angular CLI
  • Firebase Authentication
  • Firestore Database
  • Firebase Hosting
  • WebStorm

Funcionalidades implementadas

  • Autenticación de usuarios (login, registro, verificación de email)
  • Gestión de roles (usuario / administrador)
  • CRUD completo de eventos (crear, listar, actualizar y eliminar)
  • Protección de rutas mediante Guards
  • Persistencia de sesión mediante token
  • Confirmación mediante modales Bootstrap

Directivas de Angular utilizadas

Directiva Tipo Uso
*ngFor Estructural Listado dinámico de eventos
*ngIf Estructural Control de visibilidad por rol
[(ngModel)] Bidireccional Formularios de creación y edición
[routerLink] Atributo Navegación entre vistas
